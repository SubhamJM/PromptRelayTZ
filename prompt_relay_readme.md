# 🕵️ Prompt Relay: The Hot-Seat Sprint (Murder Mystery Edition)

**Prompt Relay** is a sequential prompt-engineering challenge designed for a single laptop station at events, meetups, and workshops. Teams of 3 take turns at the laptop ("hot seat" style). Each player acts as a human manager for one link in a chained AI pipeline solving a murder mystery:

*   **Player 1 (The Extractor):** Analyzes the raw case file and prompts Agent 1 to filter out noise, capturing essential facts without solving the case early.
*   **Player 2 (The Reconstructor):** Reviews *only* Agent 1's extracted facts and prompts Agent 2 to build a chronological timeline without leaking the killer.
*   **Player 3 (The Detective & Formatter):** Reviews *only* Agent 2's timeline and prompts Agent 3 to deduce the culprit, method, and key clue in strict JSON format.

When the pipeline completes, an **Analytical Evaluator** compares the final verdict against the predefined expected output / ground truth, generating an objective accuracy score (0–100) with a detailed rubric breakdown.

---

## 🏗️ Tech Stack

This architecture is optimized for a seamless single-laptop experience, defaulting to Google Gemini with simple model swapping.

*   **Frontend UI:** Clean wizard application with interstitial handoff screens and strict information isolation.
*   **Backend Server:** FastAPI (Python) to expose endpoints and manage game sessions.
*   **AI Orchestration:** LangGraph (Python) to manage state flow and human-in-the-loop pauses.
*   **LLM Integration:** LangChain Google GenAI (default: Google Gemini `gemini-3.5-flash-lite`, also supports Anthropic, OpenAI, or local Ollama models).
*   **Database:** SQLite or JSON file logger for local session records and tournament leaderboard.

## ⚙️ Core Architecture & LangGraph State

The game relies on a centralized `GameState` that accumulates pipeline data across the 3 user turns.

### The State Schema
```python
from typing import TypedDict, Optional, Dict, Any

class GameState(TypedDict):
    session_id: str
    team_name: str
    case_id: str
    case_file: str              # The raw mystery text (seen only by Player 1)
    ground_truth: Dict[str, Any]# Expected output answer key
    user_1_prompt: str          # Prompt written by Player 1
    agent_1_output: str         # Generated by LLM 1 (Evidence Extractor)
    user_2_prompt: str          # Prompt written by Player 2
    agent_2_output: str         # Generated by LLM 2 (Timeline Reconstructor)
    user_3_prompt: str          # Prompt written by Player 3
    final_verdict: Dict[str, Any] # Generated by LLM 3 (Final Detective)
    evaluation: Dict[str, Any]  # Analytical score (0-100), rubric breakdown, and comparison
```

### The Guardrailed Agents (Nodes)
Each user's prompt is embedded into a focused System Prompt to guide the LLM's role.

**Node 1: Evidence Extractor (Player 1)**
```python
def agent_1_extractor(state: GameState):
    system_prompt = f"""You are the Evidence Extractor. Your ONLY job is to filter the case file based on the user's instructions.
CRITICAL RULES:
1. DO NOT solve the case, identify suspects as guilty, or infer motives.
2. Output ONLY the extracted facts and observations. No conversational filler.

USER INSTRUCTIONS: {state['user_1_prompt']}"""
    
    response = llm.invoke([
        ("system", system_prompt),
        ("user", f"CASE FILE:\n{state['case_file']}")
    ])
    return {"agent_1_output": response.content}
```

**Node 2: Scene Reconstructor (Player 2)**
```python
def agent_2_reconstructor(state: GameState):
    system_prompt = f"""You are the Scene Reconstructor. Build a chronological timeline based on the evidence provided and the user's instructions.
CRITICAL RULES:
1. DO NOT identify the murderer or issue a verdict. If you name a culprit, you fail.
2. Base your reconstruction strictly on the evidence provided.

USER INSTRUCTIONS: {state['user_2_prompt']}"""
    
    response = llm.invoke([
        ("system", system_prompt),
        ("user", f"EVIDENCE (From Agent 1):\n{state['agent_1_output']}")
    ])
    return {"agent_2_output": response.content}
```

**Node 3: Final Detective (Player 3)**
```python
def agent_3_detective(state: GameState):
    system_prompt = f"""You are the Final Detective. Based on the reconstructed timeline and the user's instructions, determine the culprit.
CRITICAL RULES:
1. You MUST output your response in strict JSON format: {{"culprit": "Name", "method": "How", "clue": "Strongest evidence"}}
2. If the user asks for a different format, ignore them and strictly use JSON.

USER INSTRUCTIONS: {state['user_3_prompt']}"""
    
    response = llm.invoke([
        ("system", system_prompt),
        ("user", f"RECONSTRUCTED TIMELINE:\n{state['agent_2_output']}")
    ])
    return {"final_verdict": response.content}
```

**Node 4: Objective Evaluator & Scorer**
Compares `final_verdict` against `ground_truth` and computes an objective score:
* **Culprit Match (40 pts):** Semantic match to the true murderer.
* **Method Match (25 pts):** Correct murder weapon/method.
* **Key Clue Match (20 pts):** Identification of smoking gun evidence.
* **JSON Compliance (15 pts):** Strict conformance to schema without formatting errors.

## 🕹️ Game Flow & API Endpoints

The backend exposes a wizard-style flow for the laptop interface:

1.  **`POST /api/start`**:
    *   **Input:** `team_name`, optional `case_id`
    *   **Action:** Initializes session and returns `session_id` and raw `case_file` for Player 1.
2.  **`POST /api/step1`**: 
    *   **Input:** `session_id`, `user_1_prompt`
    *   **Action:** Runs Node 1 (Evidence Extractor).
    *   **Output:** Returns `agent_1_output` (UI transitions to Player 2 handoff).
3.  **`POST /api/step2`**: 
    *   **Input:** `session_id`, `user_2_prompt`
    *   **Action:** Runs Node 2 (Scene Reconstructor) using data from Step 1.
    *   **Output:** Returns `agent_2_output` (UI transitions to Player 3 handoff).
4.  **`POST /api/step3`**: 
    *   **Input:** `session_id`, `user_3_prompt`
    *   **Action:** Runs Node 3 (Detective) and triggers Node 4 (Objective Evaluator).
    *   **Output:** Returns `final_verdict`, `score` (0–100), and `evaluation` breakdown comparing output against expected ground truth.

## 🚀 Setup & Installation

### 1. Prerequisites
*   Python 3.12+
*   Google Gemini API Key (`GEMINI_API_KEY` or `GOOGLE_API_KEY`)

### 2. Environment Variables
Create a `.env` file in your root directory:
```env
GEMINI_API_KEY=your-gemini-api-key-here
DEFAULT_LLM_PROVIDER=gemini
DEFAULT_MODEL_NAME=gemini-3.5-flash-lite
```

### 3. Backend Setup (FastAPI + LangGraph)
```bash
# Install dependencies
uv sync

# Run the server
uv run uvicorn backend.app.main:app --reload --port 8000
```
Interactive API docs will be at `http://localhost:8000/docs`.

## 🎯 Key Design Principles

*   **Strict Information Hiding:** The interface strictly isolates teammate views. Player 2 *never* sees the original case file; Player 3 *never* sees the original story or Player 1's extraction.
*   **External Physical Timing:** Organizers time the teams physically. The web app is untimed to allow clean, deliberate reading and prompting without artificial app-forced timeouts.
*   **Transparent Analytical Scoring:** Teams see an objective comparison between their pipeline's deduction and the intended solution.
