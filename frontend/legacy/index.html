3-Agent Prompt Engineering Relay Competition

Orchestrate 3 Specialized AI Agents in a Prompt Relay

Teams of 3 prompt engineers craft generalized instructions for specialized AI agents. The output of Agent 1 feeds Agent 2, whose output feeds Agent 3. Score is evaluated on prompt engineering quality (60 pts) and final solution accuracy (40 pts).

1
👁️ OCR / Vision Tool

Player 1: Evidence Extractor

Crafts a generalized prompt directing Agent 1 to extract facts, times, locations, and movements while distinguishing confirmed from uncertain information without premature inferences.

2
🕸️ NetworkX Graph

Player 2: Timeline Reconstructor

Sees only Agent 1's facts and prompts Agent 2 to reconstruct chronological sequences and causal graph dependencies, keeping uncertainties separate.

3
⚙️ Z3 Constraint Solver

Player 3: Final Detective

Sees only Agent 2's timeline and prompts Agent 3 to evaluate operational rules and deduce valid actions, supporting rules, and blocking conditions in strict JSON.
